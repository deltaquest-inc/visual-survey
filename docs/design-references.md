# Design references used by this repository

Use the smallest relevant practice at the trigger below. These are pinned research sources, not instructions to install a skill, execute remote code, update dependencies or replace the approved brand. The pipeline is: identify a gap → choose a practice → produce the result → compare on the same prompt/content/viewport/theme → keep the useful local rule. No automatic upstream updates.

| When the work needs it | Pinned source | Apply and verify |
| --- | --- | --- |
| Existing page/component audit | [Impeccable](https://github.com/pbakaus/impeccable/tree/c8891a9ae865d6ee311836ae5199bfce0fe115b1) | Examine hierarchy, spacing/type, color, interaction and responsive behavior. For each finding give element/evidence, impact and repair. Measured accessibility defects block; generic style preferences require brand-aware judgment. Native engine installation is not vetted. |
| New or revised design-system contract | [Google DESIGN.md](https://github.com/google-labs-code/design.md/tree/6e5da5382f41edbba9d73b2c62f33f32e9971f15) | Make token roles, values and rationale explicit. Check parser coverage and findings rather than exit status alone. Executable theme sources remain authoritative; preserve the repo's own check and actual browser review. |
| Motion added or changed | [LottieFiles motion-design](https://github.com/LottieFiles/motion-design-skill/tree/f9a8a041b85185ee4881b3471d3415e939aac772) | Name what movement explains, sequence what leads/follows, set timing/easing, preserve reduced motion and verify keyboard/touch behavior. Remove motion that adds delay without comprehension. Practice review only; do not install engine/scripts. |

This project creates a correction interface, not promotional films. Do not add video-generation tools merely because they appear in a source collection. Provider/image-upload rules in README remain unchanged.
