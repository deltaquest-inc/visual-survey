# Image sources

All eight images are CC0 1.0 (public domain dedication). Each was checked twice on 2026-10-14:
the Openverse API record says `license: cc0`, and the source page links the CC0 1.0 deed.
CC0 asks for no credit; creators are listed anyway. Files in `images/` are the originals
downscaled to 800 px on the long side (JPEG quality 70) to keep the repository small. Machine-readable
version: `SOURCES.json`.

How the set was chosen: Openverse API (https://api.openverse.org/v1/images/), queries run 2026-10-14:

1. `q=desert vehicle&license=cc0&category=photograph&extension=jpg&page_size=20` returned 18 results; images 1 to 4 come from it.
2. `q=armor&license=cc0&category=photograph&extension=jpg&page_size=20` returned 240 results; images 5 to 8 come from it.

The comments and sentiments in `run/manifest.json` are invented for the demo.
